# Bantay promo video

A 60-second promotional video for Bantay, made with [Remotion](https://www.remotion.dev), in two sizes:

- **Vertical 1080×1920** (`BantayPromo`): Facebook Reels, TikTok, Instagram, phone screens
- **Landscape 1920×1080** (`BantayPromoLandscape`): YouTube, Facebook feed, presentations

The app screens in `public/` are real screenshots of Bantay with sample data.

```bash
cd promo
npm install
npm run studio            # preview and edit in the browser
npm run render            # writes both videos to out/
npm run render:vertical   # or just one of them
npm run render:landscape
```

## How it's put together

- `src/BantayPromo.tsx`: all scenes. `FEATURES` holds each feature's title, text, screenshots and
  floating labels; `SCENES` holds the timeline. The same scenes lay themselves out for portrait or landscape.
- The music (`public/music.mp3`) is original, generated by `scripts/make-music.py`, so it's free to use.
  It is 120 BPM: one bar is 2 seconds (60 frames), and every scene starts on a bar line so cuts land on the beat.
  Regenerate it with `npm run music` (needs Python with numpy, and ffmpeg).
- To change a screenshot, replace the PNG in `public/` with a new one of the same name.
- Inter font: SIL Open Font License.
